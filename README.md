# PinShot

接收其他应用分享的图片，将图片悬浮在其他应用上方。截图和裁剪由 OriginOS 或相册完成。

## 使用

1. 在 Android Studio 中同步 Gradle，并点击 Run 安装到手机。
2. 打开「PinShot」，允许“显示在其他应用上层”。如果首次从分享入口使用，也可以在收到图片后开启权限，返回即可钉图。
3. 选择图片 → 分享 → 选择「PinShot」→ 实现钉图。图片可以来自相册、三指拖动区域截图，或三指滑动及控制中心的普通截图。
4. 图片初始显示在屏幕上方；单指拖动图片，拖动右下角小手柄等比例放大、缩小，双击打开操作菜单：关闭当前图片、取消、逆时针旋转（每次 90°）、保存到相册或通过系统分享面板分享。保存和分享的是当前朝向的图片，不包含悬浮窗边框与手柄；保存位置为 `Pictures/PinShot`。手柄图案约为 12dp，触摸范围为 48dp。图片在左、右、上、下各方向均可移出约四分之三，水平和竖直方向各至少保留四分之一在屏幕内，方便拖回；手柄可随图片移出屏幕。图片特别大时，保留量以屏幕可用尺寸为限。最大宽高约为屏幕对应尺寸的 4 倍；最短边可缩至约 48dp。再次分享会添加一张新钉图，原有图片仍保留。

应用只接收单张图片（`ACTION_SEND`、`image/*`），支持分享 URI 位于 `EXTRA_STREAM` 或 `ClipData`。图片读取和解码在后台执行，最长边超过 4096 像素时会等比缩小以控制内存用量。无需无障碍服务、屏幕录制权限或相册全量访问权限。

应用名称为「PinShot」，保留原应用包名，可覆盖安装。旧的截图磁贴和无障碍服务已移除。

最低支持 Android 11（API 30），以 Android 16（API 36）作为编译和目标版本。

### 从首页添加图片

首页保留原有使用说明，并提供“贴图片”卡片：

- **相册**：选择一张图片，进入裁剪页。
- **相机**：调用系统相机拍照，确认照片后进入裁剪页。
- **裁剪**：拖动四角或边缘调整范围，拖动框内移动选区，点击右上角 ✓ 后钉图；× 取消。默认选中整张图片。

首次使用仍需允许悬浮窗权限。原有分享入口保持直接钉图。图片解码最长边限制为 4096 像素。

### 从首页贴文字

- **钉剪切板文字**：读取剪贴板中的文字并直接钉到屏幕上。
- **钉输入框文字**：将输入框里的内容钉到屏幕上；输入框可手动输入，也支持系统粘贴。
- **CTRL+V粘贴**：把剪贴板文字插入输入框当前光标位置。
- **清空输入框**：清除输入框中的文字。

剪贴板不是文字或内容为空时会显示提示。文字会绘制成白底图片，使用与图片钉图相同的拖动、缩放和双击菜单。内容过长时会提示缩短，以免生成被截断的图片。

首页的“更多说明”打开使用说明弹窗；“分享技巧”打开四步图文教程，说明如何在 OriginOS 图片分享面板中将 PinShot 加入置顶服务。教程截图已随应用打包。输入框获得焦点且输入法出现时，页面会滚动使输入框和两排文字按钮保持可见。
