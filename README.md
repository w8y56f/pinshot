# 钉图截图（PinShot）

一个为 Android 设计的轻量截图钉图工具：从控制中心触发区域截图，随后把选区以可拖动、等比缩放的悬浮图显示在其他应用上方。

## 在 Android Studio 中打开

1. 使用 Android Studio 打开本目录。
2. 等待 Gradle 同步，并按提示安装 Android SDK Platform 36（Android 16）。
3. 安装到手机。首次运行时，允许“显示在其他应用的上层”。
4. 在控制中心的编辑界面添加「钉图截图」磁贴。

每次截图时 Android 都会显示系统的屏幕录制授权提示。完成区域选择后按「钉图」。钉图支持单指拖动、双指等比缩放，双击后确认即可关闭。

最低支持 Android 10（API 29），以 Android 16（API 36）作为编译和目标版本。
